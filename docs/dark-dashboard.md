# Reference-led merchant dashboard

The user's supplied dark analytics reference guides the charcoal surfaces, restrained purple and lime chart accents, compact metrics, and simpler typography. Kora retains its existing logo.

Overview charts use actual merchant data: per-variant opening quantities and selling value, plus the distribution of stocked, zero-stock, and uncounted variants. Units and Value are selectable. Charts have visible text equivalents and no remote dependencies. Recent activity is the latest five tenant-scoped opening stock records; it is not a revenue or sales chart.

Sidebar collapse persists on desktop where browser storage is available. Icon-only links retain accessible names. Phones start with navigation hidden behind an expandable control; Escape closes it. Without JavaScript, navigation and ordinary server forms remain available. Working pages use the same dark palette with compact headings.

Verified locally in Chrome: complete account/business/product/stock/team workflow; chart switching; sidebar collapse and persistence; keyboard menu control; overview, products, inventory and team at 360, 390, 640, 768, 1024 and 1440 pixels. All 43 backend tests passed. Screenshots were reviewed and a currency encoding issue corrected. Safari, Firefox, assistive technology and production database concurrency remain unverified.
